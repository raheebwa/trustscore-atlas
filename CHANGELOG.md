## [Unreleased]

### Added

- Public business search and exploration with country, sector, location, and register-presence filters.
- Per-business records with field-level provenance, evidence, linkage candidates, and paths to claim a business or report a problem.
- A source registry showing each publisher, licence, refresh cadence, and last accepted run.
- A methodology page generated from the live rubrics, country bindings, precedence rules, and linkage rules.
- Canonical and per-source downloadable data packages with source rights and attribution carried alongside the data.
- A JSON API for public reads and confirmation-mediated reports, claims, and corrections.
- A Uganda reference pack and a Kenya regulator-directory adapter that demonstrate the country-pack contract.
- Scheduled refresh and rollback workflows with an identity-churn guard.
- Browser tools and a read-only remote MCP endpoint for searching records, inspecting evidence, explaining scores, and exploring segments.
